## Booking System

Python program based on the concept of **booking**.

The system is designed around the idea that **anything that can potentially be booked, can be represented as a bookable resource or service**. It could be a hotel room, sports facility, meeting room, activity, appointment, vehicle, equipment, or another type of resource or service.

### Domain

- abstract bookable entities (resources or services)
- customers
- availability
- booking status
- creating and cancelling bookings
- changing bookings
- prices or costs
- searching and filtering bookings
- summaries of available and booked resources

## Run

Requires Python 3.8 or later. From the project root, start the booking system with:

```console
python -m bookable
```
