# Lexicon Python Labs

This repository contains a set of Python exercises and practice labs.

## Project structure

- `Lab1/` - Python Basics
- `Lab2/` - Collections in Python
- `Lab3/` - Conditions and Loops
- `Lab4/` - Functions
- `Lab5/` - Scope and Flexible Function Arguments
- `Lab6/` - Comprehensions, Enumeration, Zip and Sorting
- `Lab7/` - Classes and Objects
- `Lab8/` - Object-Oriented Programming
- `Checkpoints/` - checkpoint-style practice files

## Running the labs

From the project root, run a file with Python, for example:

```bash
python "Lab1/lab1.py"
```

## Notes

- `pass` indicates that the task was straightforward enough to be solved immediately
